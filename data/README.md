# Data contract and access note

No raw or processed data are included. The study used restricted data supplied for dissertation research; do not attempt to reconstruct or publish that dataset from this code.

To run the pipeline with independently authorised data, create these local paths. They are all ignored by Git:

```text
data/
├── transfermarkt_public/
│   ├── appearances.csv
│   ├── club_games.csv
│   ├── competitions.csv
│   ├── games.csv
│   └── players.csv
├── club_elo_ratings.csv
├── injuries/injuries.csv
├── external/transfermarkt_two_tiers_2000_2025/
│   ├── career_appearances/career_club_appearances.parquet
│   ├── normalized_full/club_seasons.parquet
│   └── normalized_full/players.parquet
└── processed/                 # generated by the pipeline
```

The final pipeline requires match dates, competition IDs, player/club IDs, minutes played, player metadata, injury dates/days lost and dated ClubElo ratings. Extension files are required to reproduce the complete 13-league 2000-2025 panel.

Before use, check identifier mapping across sources, confirm two club sides and two pre-match Elo values for retained matches, preserve dates and source season labels, and review all licensing, contract, privacy and access restrictions.
